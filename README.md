# 桌面工作台 (Desktop Workbench)

PC 桌面级个人工作台：桌面覆盖层 + 文件整理 + 快捷入口 + 待办/便签/打卡 + 番茄钟 + 剪贴板历史 + 截图取字 + 自动时间统计。

## 功能

- **桌面覆盖模式**：工作台铺满桌面（不遮挡任务栏），可切换普通窗口；支持 Win11 亚克力毛玻璃
- **快捷入口**：常用应用/文件一键启动，图标自动提取
- **文件整理**：文件/文件夹拖拽分组收纳；自动整理规则（监控文件夹按扩展名/关键词归类）
- **待办**：优先级、截止日期/时间、重复任务、子任务、备注、到期系统通知
- **日历**：按月查看待办分布
- **便签 / 习惯打卡**（连续天数统计）
- **番茄钟**：专注/短休/长休，完成计数
- **剪贴板历史**（Win+Alt+V）：自动记录文本/图片/文件，支持搜索、置顶、类型过滤，图片 OCR 提字
- **截图 OCR 取字**（Win+Alt+S）：框选屏幕区域，离线识别文字并自动复制
- **命令面板**（Ctrl+K）：搜索内容 + 直接执行动作（新建待办/便签、切换主题、开始专注等）
- **自动时间统计**（可选，仅 Windows）：后台记录各应用使用时长并按规则自动分类
- **桌面小组件**：时钟 / 今日待办 / 便签 可固定为桌面小窗
- **数据洞察**：待办完成率、近 14 天活跃度、时间统计汇总
- 全局快捷键：Win+Alt+Space 显隐工作台 · Win+Alt+T 快速添加待办 · Win+Alt+V 剪贴板历史 · Win+Alt+S 截图取字
- 数据本地存储（原子写入 + 自动备份 + 导出/导入）

## 开发

```bash
npm install        # 安装依赖（仅 electron / electron-builder 等开发依赖）
npm start          # 本地运行
npm run dist       # 生成 Windows 安装包（dist 目录）
```

OCR 使用内置离线模型（ocr-data/chi_sim + eng），无需联网。

## 说明

- 用户数据保存在 %APPDATA%\桌面工作台，与应用分离，升级不丢失
- 时间统计数据独立存放 usage-data.json，自动保留 90 天
- 仅 Windows 支持剪贴板历史 / 截图取字 / 自动时间统计（其余功能跨平台）
